## Usage

Each skill is a Claude-compatible instruction file. To use a skill:

1. Open the `.md` file
2. Copy the content into a Claude Project instruction or custom GPT system prompt
3. Configure any `[YOUR_*]` placeholders with your own credentials and IDs
4. Invoke using one of the trigger phrases listed in the file

Skills marked **Archived** are preserved for reference but have been superseded by newer unified skills.
