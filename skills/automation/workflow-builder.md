# Workflow Builder

> Converts plain-English automation requests into production-ready n8n workflow specs.

## What It Does
Takes any natural language automation description and produces a complete n8n workflow specification: trigger setup, node architecture, branching logic, credential requirements, error handling patterns, and a deployment checklist.

## Use Cases
- Spec out a new automation from a brief
- Design an event-driven notification pipeline
- Build a multi-step data enrichment workflow
- Create a webhook-triggered CRM update flow

## Tech Stack
- n8n
- Make
- Zapier
- API Design
- Webhook Architecture

## Trigger Phrases
- "build this workflow"
- "automate this process"
- "design the n8n flow for"
