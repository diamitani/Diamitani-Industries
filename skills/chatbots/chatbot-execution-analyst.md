# Chatbot Execution Analyst

> Monitors chatbot automation pipelines — health, throughput, and conversion metrics.

## What It Does
Technical analyst for chatbot execution infrastructure. Monitors message delivery rates, MQL workflow trigger health, handoff success rates, and conversion funnel integrity. Produces HTML health dashboards from execution log data.

## Use Cases
- Check chatbot pipeline execution health
- Debug a failed MQL classification workflow
- Generate a throughput and conversion report
- Identify bottlenecks in the lead handoff pipeline

## Tech Stack
- n8n
- HubSpot
- Monitoring
- API

## Trigger Phrases
- "check chatbot execution"
- "why did the bot fail"
- "pipeline health report"
- "chatbot throughput"

## Setup
Configure `[YOUR_WORKFLOW_IDS]` for your specific MQL classification and delivery workflows.
