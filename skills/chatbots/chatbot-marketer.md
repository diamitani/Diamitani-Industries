# Chatbot Marketer

> Generates copy and campaigns for marketing chatbot flows.

## What It Does
Marketing-focused chatbot content skill. Generates copy, campaigns, and messaging for chatbot flows — from welcome greetings through qualification scripts to follow-up sequences. Outputs concise, conversational, mobile-first copy with A/B variants.

## Use Cases
- Write a new chatbot welcome flow
- Create a qualification script for a product segment
- Draft A/B variants for an opening message
- Build a campaign-specific chatbot entry experience

- Conversation Design
