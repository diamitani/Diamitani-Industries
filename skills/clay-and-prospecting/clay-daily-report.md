# Clay Daily Report

> Daily Clay.com enrichment run summary — contacts pulled, credit spend, hit rates.

## What It Does
Generates a daily report from Clay enrichment runs. Summarizes contact pulls, credit spend, enrichment hit rates by data provider, error counts, and flags any unusual spend patterns.

## Use Cases
- Review yesterday's Clay enrichment run
- Monitor daily credit spend and hit rates
- Flag enrichment failures for investigation
- Track provider-level hit rates over time

## Tech Stack
- Clay API
- n8n
- Reporting
- Cost Monitoring

## Trigger Phrases
- "Clay daily report"
- "how did the enrichment run"
- "credit spend for today"
- "Clay hit rates"

## Setup
Configure `[YOUR_CLAY_API_KEY]` and the enrichment table IDs to monitor.
