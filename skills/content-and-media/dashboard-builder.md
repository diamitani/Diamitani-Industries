# Dashboard Builder

> Builds executive dashboards and reporting views from any raw data.

## What It Does
Generates structured HTML reporting layouts from raw data inputs. Designed for executive reporting, board presentations, and operations dashboards. Outputs clean HTML with KPI tiles, trend indicators, and data tables.

## Use Cases
- Build a weekly GTM metrics dashboard
- Create a board-ready KPI report
- Generate an operations health view
- Turn a CSV into a visual dashboard

## Tech Stack
- Claude
- HTML/CSS
- Data Visualization
- CSV

- "create a report view"
- "make an exec dashboard"
- "visualize this data"
