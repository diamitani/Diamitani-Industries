# Presentations Builder

> Builds polished slide decks and executive presentations from any brief.

## What It Does
Full presentation builder for 2026 decks. Takes any brief, company context, or data input and generates a fully structured, branded slide deck. Outputs to .pptx via python-pptx. Configure your own brand template.

## Use Cases
- Build a quarterly business review deck
- Create a board presentation
- Generate a partner pitch from a brief
- Build a demo deck for a specific account

## Tech Stack
- python-pptx
- Claude
- Template Engine
- Brand Assets

## Trigger Phrases
- "build a presentation"
- "create a deck"
- "make slides"
- "presentation about"

## Setup
Configure `[YOUR_BRAND_TEMPLATE]`, `[YOUR_COMPANY_NAME]`, and `[YOUR_BRAND_COLORS]`. Provide your own .pptx template file.
