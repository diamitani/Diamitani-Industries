# Video Studio

> AI video builder using HyperFrames and Chatterbox TTS — prompt to MP4.

## What It Does
Autonomous video builder using HeyGen HyperFrames (HTML-to-video pipeline) and Chatterbox-Turbo TTS. Accepts a brief or script, renders a complete branded MP4: title cards, overlays, caption-synced audio, scene transitions.

## Use Cases
- Create a LinkedIn explainer video
- Build a product demo video
- Generate a presentation video from slides
- Produce a short-form social media video

## Tech Stack
- HyperFrames
- Chatterbox TTS
- Node.js
- ffmpeg
- n8n

## Trigger Phrases
- "make a video"
- "build a video for"
- "render a LinkedIn video"
- "video from this script"

## Setup
Configure your brand assets: `[YOUR_BRAND_FONT]`, `[YOUR_BRAND_COLORS]`, `[YOUR_LOGO_PATH]`. Install HyperFrames and Chatterbox via the skill's auto-installer.

## Notes
