# GTM Agent OS

> ROSTR-powered multi-agent operating system for the full prospecting stack.

## What It Does
Full GTM Agent OS built on the ROSTR framework. Orchestrates Clay, HubSpot, n8n, and outreach tools in a unified agent loop. Acts as an autonomous GTM operator — polls intent, runs ICP checks, manages enrichment queues, stamps CRM, and reports on workflow health.

## Use Cases
- Run the full daily GTM agent loop
- Fix and diagnose prospecting automation
- Check pipeline health across tools
- Manage enrichment queues and CRM hygiene

## Tech Stack
- Claude
- ROSTR
- Clay
- HubSpot
- n8n
- Amplemarket

## Setup
Configure `[YOUR_COMPANY_*]` placeholders: CRM instance URL, n8n endpoint, Clay API key, outreach tool credentials. See the full skill source in the sanitized skill file.
