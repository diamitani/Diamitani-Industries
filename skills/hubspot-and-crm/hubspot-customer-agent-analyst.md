# HubSpot Customer Agent Analyst

> Analyzes HubSpot customer agent conversations — trends, escalations, resolution rates.

## What It Does
Pulls and analyzes HubSpot customer agent conversation data. Summarizes interaction trends, identifies escalation patterns, measures resolution rates, and surfaces improvement opportunities for chatbot and live agent workflows.

## Use Cases
- Generate a weekly chatbot conversation report
- Identify top escalation categories
- Measure agent resolution rates
- Spot patterns in unresolved conversations

## Tech Stack
- HubSpot API
- Python
- Analytics
- Reporting
