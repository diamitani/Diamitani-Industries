# HubSpot Import Formatter

> Any spreadsheet to a clean, deduplicated, NAICS-enriched HubSpot import file.

## What It Does
Formats raw data exports into HubSpot-ready import CSVs. Maps fields to HubSpot properties, cleans data, deduplicates by email/domain, validates required columns, and enriches with NAICS industry codes.

## Use Cases
- Format a raw contact list for HubSpot import
- Deduplicate a prospect CSV before upload
- Map custom columns to HubSpot properties
- Enrich a list with NAICS codes

- NAICS Lookup
