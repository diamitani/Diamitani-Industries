# Diagram Builder

> Builds technical and process diagrams from plain-English descriptions.

## What It Does
Takes any system, workflow, or process description and outputs a clean diagram in Mermaid, PlantUML, or SVG. Covers architecture diagrams, sequence diagrams, ERDs, flowcharts, and state machines.

## Use Cases
- Create a system architecture diagram
- Build a workflow sequence diagram
- Document an API flow as a diagram
- Visualize a multi-agent pipeline

## Tech Stack
- Mermaid
- PlantUML
- SVG
- Diagram Design

## Trigger Phrases
- "draw a diagram"
- "architecture diagram for"
- "sequence diagram of"
- "visualize this workflow"
