# Instruction Architect

> Designs Claude instruction stacks and multi-layer agent instruction hierarchies.

## What It Does
Builds Claude system prompts, skill instruction files, and multi-agent instruction hierarchies. Applies prompt engineering best practices, ROSTR framework conventions, and production discipline (dry-run defaults, audit trails, cost awareness).

## Use Cases
- Design a system prompt for a new agent
- Structure a multi-agent instruction hierarchy
- Review and improve an existing Claude skill
- Build a skill file from a rough description

## Tech Stack
- Claude
- Prompt Engineering
- ROSTR
- Multi-Agent Design
