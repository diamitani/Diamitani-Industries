# JTBD Builder

> Jobs-To-Be-Done framework — generates user stories, pain points, and value propositions.

## What It Does
Builds a complete JTBD analysis from a product or feature description. Identifies the core job the user is hiring the product to do, maps functional/emotional/social jobs, surfaces pain points, and generates value propositions.

## Use Cases
- Define the core job for a new product
- Build user stories for a feature sprint
- Identify underserved customer segments
- Write value propositions grounded in JTBD theory

## Tech Stack
- Claude
- Framework Design
- Product Management
