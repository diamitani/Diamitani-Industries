# NPAO Framework

> Need-Problem-Action-Outcome — structures problem statements and solution designs.

## What It Does
NPAO is a four-part framework for structuring any GTM, product, or ops problem before building a solution. Forces clarity on what the need is, what problem blocks it, what action will be taken, and what outcome success looks like.

## Use Cases
- Structure a build brief before starting work
- Write a problem statement for a stakeholder
- Align a team on scope and expected outcomes
- Frame a project intake document
