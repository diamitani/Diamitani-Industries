# PRD Builder

> Generates a full Product Requirements Document from a brief input.

## What It Does
Takes any product description, brief, or rough idea and outputs a complete PRD: problem statement, user personas, user stories, acceptance criteria, technical requirements, milestones, and success metrics.

## Use Cases
- Write a PRD for a new feature
- Document an AI system for engineering handoff
- Create acceptance criteria for a sprint
- Build a technical spec from a founder brief

## Tech Stack
- Claude
- PRD Templates
- Product Management

## Trigger Phrases
- "build a PRD"
- "write the product spec"
- "document this feature"
- "PRD for"
