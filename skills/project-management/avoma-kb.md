# Avoma Knowledge Base

> Retrieves call recordings, transcripts, and AI insights from Avoma.

## What It Does
Connects to Avoma and retrieves transcripts, summary notes, and AI-generated insights for specified calls or deals. Formats into coaching-ready reports or deal-prep briefs.

## Use Cases
- Pull a transcript for a specific deal
- Get AI coaching insights from recent calls
- Brief a rep before a call using past conversation data
- Retrieve competitive mentions from call recordings

## Tech Stack
- Avoma API
- Claude
- Sales Intelligence

## Trigger Phrases
- "pull Avoma data"
- "get the call transcript"
- "Avoma insights for this deal"
- "coaching report from calls"

## Setup
Requires `[YOUR_AVOMA_API_KEY]`.
