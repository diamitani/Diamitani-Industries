# Case Study Builder

> Turns project artifacts into portfolio-ready case studies.

## What It Does
Takes any pile of project artifacts — docs, data, screenshots, notes, chat threads — and structures them into a complete case study and troubleshooting report. Covers overview, problem, how it works, stack, setup, results, and lessons learned.

## Use Cases
- Write up a completed build for a portfolio
- Document an AI system for a client
- Turn a Slack thread into a case study
- Create a results report for a stakeholder
