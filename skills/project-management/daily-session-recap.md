# Daily Session Recap

> Generates structured end-of-day recap — what was built, decisions made, next steps.

## What It Does
Reviews the full session and produces a structured daily recap: what was accomplished by project, decisions made, open questions, blockers, next steps, and estimated time allocation.

## Use Cases
- Generate an end-of-day summary
- Create a status update for a manager
- Log daily progress for future context retrieval
- Recap a build session for handoff

## Tech Stack
- Claude
- Context Engine
- Flat Files

## Trigger Phrases
- "recap today"
- "end of day summary"
- "session recap"
- "what did we accomplish"
- "daily recap"
