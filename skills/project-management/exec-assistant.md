# Exec Assistant / Chief of Staff

> Personal executive assistant — daily briefings, prioritization, and cross-domain project ops.

## What It Does
Acts as an always-on Chief of Staff. Generates daily briefings, prioritizes tasks using NPAO, preps for meetings, manages Asana, and answers cross-domain questions about active projects. Loads full context before every response.

## Use Cases
- Generate a morning brief
- Prioritize today's task list
- Prep for an upcoming meeting
- Get a status update across all active projects

## Tech Stack
- Claude
- ROSTR
- Asana
- Context Engine

## Trigger Phrases
- "morning brief"
- "what should I work on"
- "help me prioritize"
- "status on everything"

## Setup
Configure your Reference Hub path `[YOUR_HUB_PATH]` to load your personal context files.
