# New Project Intake

> Standalone structured intake form for any new project.

## What It Does
Standalone project intake skill. Walks through a structured intake: project name, goal, stakeholders, scope, constraints, success metrics, and timeline. Outputs a filled intake doc ready for planning.

## Use Cases
- Intake a new client project
- Scope a feature request
- Document a new initiative before planning

## Tech Stack
- Claude
- Project Management
- Templates

## Trigger Phrases
- "new project intake"
- "intake this project"
- "scope this idea"
