# New Project JTBD Builder

> JTBD (Jobs-To-Be-Done) builder scoped for new project intake.

## What It Does
Runs a JTBD analysis as part of new project intake. Identifies the core job, user personas, pain points, and competing approaches. Feeds into the PRD and positioning.

## Use Cases
- Define who the product is for and why
- Surface the job the project is solving
- Identify competing approaches the user already tries

## Tech Stack
- Claude
- Framework Design
- JTBD

## Trigger Phrases
- "JTBD for this project"
- "who is this for"
- "what job are we solving"
