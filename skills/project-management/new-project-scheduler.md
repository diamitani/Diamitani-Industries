# New Project Scheduler

> Schedules project milestones and sprint cycles from intake data.

## What It Does
Takes a scoped project and generates a sprint schedule with milestones, effort estimates, and dependency mapping. Outputs a timeline ready for Asana, Linear, or any PM tool.

## Use Cases
- Schedule sprints for a new project
- Build a milestone timeline from a PRD
- Map task dependencies and critical path

## Tech Stack
- Claude
- Project Management
- Asana

## Trigger Phrases
- "schedule this project"
- "build a sprint plan"
- "milestone timeline for"
