# New Project System

> Idea-to-execution engine — any input to leadership-ready package in under 30 minutes.

## What It Does
The unified project intake system. Accepts any raw idea, request, or brief and outputs a complete package: PRD, architecture diagram, build plan, KPI framework, sprint schedule, and PM tool export. Combines intake, JTBD builder, and scheduler in one skill.

## Use Cases
- Turn a Slack message into a scoped project
- Build a leadership-ready project brief from rough notes
- Generate a sprint plan from a feature description
- Create a full project package for Asana or Linear
