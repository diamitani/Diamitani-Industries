# Project Handoff Generator

> Creates structured transition documents for stakeholder or team handoffs.

## What It Does
Generates professional project handoff documents from current project context. Covers background, what was built, architectural decisions, known issues, open items, contacts, and recommended next steps.

## Use Cases
- Hand off a project to a new team member
- Document a system before going on leave
- Create a transition brief for a client

## Tech Stack
- Claude
- Documentation
- Templates

## Trigger Phrases
- "create a handoff doc"
- "write the transition brief"
- "project handoff for"
