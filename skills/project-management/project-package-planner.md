# Project Package Planner

> Plans and scopes deliverable packages — milestones, effort estimates, dependencies.

## What It Does
Takes a project goal and produces a complete deliverable package plan: scoped milestones, effort estimates for each, dependency map, and risk flags. Designed for client projects and internal product work.

## Use Cases
- Scope a client deliverable package
- Estimate effort for a project
- Map deliverable dependencies before kicking off

## Tech Stack
- Claude
- Project Management
- Estimation

## Trigger Phrases
- "plan this project package"
- "scope the deliverables"
- "estimate effort for"
