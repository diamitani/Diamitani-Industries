# RFP Answer Retriever

> Semantic search against the RFP knowledge base — HIGH/MEDIUM/NO MATCH confidence scoring.

## What It Does
Phase 2 of the RFP Suite. Accepts any RFP question and runs semantic search against the knowledge base. Returns matches with confidence scores (HIGH/MEDIUM/NO MATCH), auto-creates HubSpot tickets for gaps, and supports batch processing.

## Use Cases
- Answer a single RFP question against the KB
- Batch-process an entire RFP
- Identify questions with no existing answers
- Auto-create tickets for knowledge gaps

## Tech Stack
- Claude
- HubSpot API
- Semantic Search
- Batch Processing

## Trigger Phrases
- "answer this RFP question"
- "search the RFP KB"
- "what do we have for this question"
- "batch process this RFP"
